# Manual title-belt overrides

**Purpose:** attach a belt to a bout when the source names every other belt on the card but
not that one.

`data/overrides/title_belts.jsonl`, applied by `scrapers/derive/belts.py`. 55 rows.

Everything else in the belt pipeline is derived from what Tapology prints. This file is the
one place where an outside source is allowed in, so it is kept small, sourced line by line,
and fenced by rules that make it unable to invent anything.

---

## 1. Why it has to exist

The Ring Magazine title is not a sanctioning body. It sanctions no fights, orders no
mandatories and collects no fees — it is a magazine's merit title, "the man who beat the
man". So when a bout unifies it with the alphabet belts, Tapology frequently bills the
fight by the sanctioning bodies alone and the Ring component simply is not in the string.

Shields vs Hammer, 13 April 2019, reads:

```
Undisputed Female Middleweight Title
```

"Undisputed" expands to the four majors (see `belts.md`), and that is correct — undisputed
*means* WBC + WBA + IBF + WBO. It does not mean Ring. But that fight also crowned the
inaugural Ring female middleweight champion, and there is nothing in the string to infer it
from. No parsing rule can recover it; it needs ground truth.

**Measured against the 24 women's Ring title fights we hold, Tapology names Ring on 9 —
it is missing on 15, 63%.** This is not an edge case.

---

## 2. Row shape

```json
{"bout_slug": "412829-shields-vs-hammer-claressa-t-rex-shields-vs-christina-hammer",
 "event_date": "2019-04-13", "add_authority": "ring magazine",
 "division": "middleweight", "gender": "F", "champion": "Claressa Shields",
 "source": "Wikipedia: List of The Ring world champions (women)"}
```

`source` is mandatory in practice — a row without a citation is a guess with extra steps.

---

## 3. Three rules that keep it honest

- **An override can only attach a belt to a bout we already hold.** `bout_slug` must match
  an existing link or the row is skipped. It can never create a fight, a fighter or a date.
- **Every injected link carries an `override` field naming the source**, so a belt link that
  came from outside the source is always distinguishable from one Tapology stated.
- **Unmatched rows are skipped silently, never fabricated.** A stale slug degrades to
  nothing rather than to something wrong.


Only ~24% of the Ring men's history is reachable, and Tapology already had 59% of that.
Ring Magazine coverage overall went from **147 to 203 bouts** across 36 belts.

## 5. Matching, and how it goes wrong

Rows were generated by matching **champion surname + exact date** against boxing bouts in
the corpus. Two failure modes showed up and both are guarded:

- **Surname collisions on the same date.** "Jesse Rodriguez, 2024-06-29" first matched
  *Nathan* Rodriguez vs Jose Saant on a WBC FECARBOX regional strap. Candidates are now
  ranked by how world-level their existing belts are — a Ring title sits beside the majors,
  never beside a regional belt — and the real Estrada vs Rodriguez bout turned out to carry
  Ring already, so it was correctly skipped rather than double-added.
- **A guard that was too strict** rejected 7 fights that looked like misses (Jones vs
  Tarver II, Hopkins vs Calzaghe, Pacquiao vs Barrera). All 7 already carried
  `body:ring magazine` and were never override candidates. Worth checking before reporting
  a miss.

Only reigns that **began by winning a bout** are transcribed. "Awarded", "reinstated" and
retroactive entries — Naseem Hamed's 2019 featherweight award — have no bout to attach to.

---

## 6. Adding to it

Generate candidates, verify them by eye against the existing belts on each bout, then
append. Re-run `belts.py` -> `belt_lineage.py` -> `bout_title_stakes.py`. The count printed
by `belts.py` (`manual title-belt overrides applied: N`) should equal the file's row count;
a shortfall means a `bout_slug` no longer matches.
